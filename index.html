Domande Frequenti (FAQ Architettura & Sicurezza)

❓ 1. Perché l'architettura a 4 livelli in Rust è superiore ai WAF ed ai firewall tradizionali?

I WAF tradizionali sono filtri IP/HTTP statici che non comprendono il linguaggio naturale o l'intento malevolo. ANTAI lavora direttamente sul socket a < 0.05 microsecondi in Rust prima dell'inferenza LLM, isola le minacce in sandbox Beelzebub e sintetizza anticorpi molecolari immutabili a costo 0$.

❓ 2. ANTAI funziona con modelli locali (es. Ollama) o solo con i Cloud (OpenRouter / Groq)?

ANTAI è progettato per funzionare al 100% in locale con zero costi API integrandosi con Ollama (http://127.0.0.1:11434) ed LM Studio. Allo stesso tempo, supporta l'integrazione asincrona verso OpenRouter o Groq per la classificazione semantica complessa in cloud.

❓ 3. Cos'è il Beelzebub Deception Fabric e perché serve un Honeypot MCP?

Quando un attacco spinge un agente autonomo ad eseguire comandi pericolosi (es. rm -rf / o richiedere chiavi IAM AWS), Beelzebub serve una risposta fittizia plausibile. L'hacker crede di essere riuscito ad infettare il sistema, mentre in realtà è intrappolato nel sandbox ed ANTAI memorizza la firma dell'anticorpo.

❓ 4. Come integro ANTAI nella mia applicazione Web (Lovable, Bolt.new, Next.js, Python)?

Basta includere lo script nativo http://127.0.0.1:8090/sdk/antai-sdk.js nel tuo HTML o usare il wrapper AntaiMiddleware nei tuoi server Python/FastAPI o Node.js. Trovi il codice pronto nella scheda 04 SDK Integration Hub.

❓ 5. ANTAI rallenta il mio computer o aggiunge latenza alle risposte IA?

Assolutamente no. Il backend compilato in Rust consuma meno di 10 MB di RAM ed una percentuale di CPU impercettibile (< 0.1%). Il Layer 1 aggiunge una latenza deterministica inferiore a 0.05 microsecondi, impercettibile per l'utente umano.
